# Unser Projekt über Wirtschaftgeschichte
Leandro, Marko und ich haben diese Webseite zusammen, in einem Team als Schulprojekt, programmiert sowie kreiert. Die Webseite handelt über die Wirtschaftsgeschichte von China, und erklärt wie China in ihre gegenwärtige Machtwirtschaft gekommen ist. Zuletzt gibt es auch ein kleines Quiz wo die Benutzer sehen können, ob die was von unserer Webseite mitnehmen konnten. Zusammen haben wir sehr viel Spass gehabt, es hat mich auf jeden Fall gefreut mit Marko und Leandro arbeiten zu können. [Hier](https://www.chi-history.vercel.app/) können Sie unsere Webseite besuchen, eine weitere Domain finden Sie [hier](https://www.chi-history.com/).
